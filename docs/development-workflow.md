# Flujo de Trabajo en Desarrollo

## Ramas Git
- Las ramas deben tener el prefijo: `feat/`, `fix/`, o `chore/`.
- La rama base para la infraestructura es: `chore/django-docker-foundation`.

## Ejecución Local
```bash
# Iniciar desarrollo
./scripts/dev.ps1   # Windows PowerShell
./scripts/dev.sh    # Linux / macOS
```
